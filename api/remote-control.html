Harmoneasy remote control

Control Harmoneasy from this page without pairing: play notes, bend pitch, run the transport and press any control in its command palette.

1. Open Harmoneasy

Harmoneasy builds that send Cross-Origin-Opener-Policy: same-origin cut the link to a window that opens them; embed those instead. Browser audio still needs a click inside Harmoneasy.

2. Allow control and connect

In Harmoneasy, open the audioBus Protocol input in the graph, tick Accept control from any window without pairing and press its Connect button. Then press Connect here. Connecting keeps trying for 15 seconds.
