Demos

Each demo runs the built SDK from dist/ in your browser. Window demos open a popup, so allow popups for this site.

Two browser windows

  • Pairing codes and retained state

    The popup did not choose its peer, so it shows a code. Enter it to connect, then watch tempo state arrive with the subscription and follow changes.

    Open demo · Source

  • Two peers, symmetric commands

    Open a second window, discover its commands and set its tempo. Both windows expose the same command.

    Open demo · Source

  • MIDI and command destination

    A receiver for Harmoneasy's audioBus Protocol Output: notes, UMP, tempo commands, panic and patches, with optional sound.

    Open receiver · Source

To use the receiver, enter this page's examples/receiver.html address as the destination URL in Harmoneasy's Output and open it from there. The receiver needs a window reference to its opener, so opening it directly only shows the page.
